# PrivateDesk Starter — Read-only 0.4

## עדכון מדידת CPU
הגרסה הזו מחליפה את מדידת CPU ל-GetSystemTimes של Windows. החישוב מבוסס על הפרשי מונים מצטברים בין בקשות עוקבות:
CPU% = 100 × (1 − ΔIdle / (ΔKernel + ΔUser)).
Kernel time כולל Idle time. המדידה היא ממוצע מערכתי על פני חלון הזמן שבין שתי בקשות, ומנורמלת לכל המעבדים הלוגיים — בדומה לאחוז הכולל ב-Task Manager.

הדגימה הראשונה רק מאתחלת נקודת ייחוס, ולכן תציג —; אחרי בקשת העדכון הבאה יופיע ערך.

## הפעלה
1. עצור את הגרסה הקודמת בחלון PowerShell באמצעות Ctrl+C.
2. חלץ את החבילה החדשה לתיקייה נפרדת.
3. פתח PowerShell רגיל בתיקייה והריץ `.\PrivateDesk-Bridge.ps1`.
4. פתח במחשב `http://127.0.0.1:8765/` ורענן פעם אחת אם צריך.

## אבטחה וביצועים
- שרת Loopback בלבד: 127.0.0.1:8765.
- API קריאה בלבד: `/health` וממשק HTML.
- אין הרצת פקודות, גישה לקבצים לפי בקשת משתמש או פעולות שליטה.
- CPU נמדד בשתי קריאות Win32 קצרות בעת בקשת health. אין polling בצד השרת.
- RAM נקרא באמצעות Windows Performance Counter.
- אין לפתוח פורטים לרשת ואין להוסיף חריגות Norton/Firewall.
- זהו אב-טיפוס; יש להשוות מול Task Manager לאורך כמה דגימות. אין הבטחה להתאמה של 100% בכל גרסת Windows או תצורת מערכת.
